Proyek ini merupakan game 2D yang dikembangkan menggunakan Unity dan bahasa pemrograman C#. Game ini dibuat sebagai sarana pembelajaran dalam pengembangan game, mulai dari perancangan gameplay, pembuatan antarmuka pengguna, implementasi animasi, hingga pengelolaan sistem skor dan mekanisme permainan.
Melalui proyek ini, berbagai konsep dasar pengembangan game diterapkan, seperti pergerakan karakter, deteksi tabrakan, manajemen objek, dan logika permainan. Selain itu, proyek ini juga bertujuan untuk meningkatkan keterampilan dalam menggunakan Unity Engine serta pemrograman berbasis C#.
Repository ini berisi seluruh aset dan source code yang digunakan dalam pengembangan game.
